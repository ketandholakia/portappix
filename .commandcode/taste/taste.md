# Taste

## Coding Style

- Prefers zero third-party libraries/components in Delphi projects; stick to the standard RTL/VCL units unless a third-party dependency is explicitly requested. Confidence: 0.85
- Prefers modern Object Pascal idioms — inline variables, generics, interfaces — rather than legacy-style declarations. Confidence: 0.75
- Wants UI logic and business logic kept in separate units; engine/core code should be written and testable independently of Forms. Confidence: 0.8
